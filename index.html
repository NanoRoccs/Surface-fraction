Surface fraction: f = 1 − (1 − 2t / D)p with shell depth t = n × d (n layers, d = layer spacing). The exponent p is the number of dimensions that shrink: 3 for a sphere or cube, 2 for a long nanowire, 1 for a thin film (two faces). A sphere of diameter D and a cube of edge D have the same surface-to-volume ratio (6/D), so they follow the same curve. When D ≤ 2t there is no core left: every atom is a surface atom.
Gold: FCC, a = 0.4078 nm → 58.97 atoms/nm³, d111 = a/√3 = 0.2355 nm, d100 = a/2 = 0.2039 nm, atomic radius 0.144 nm. Atom counts use the continuum volume; the cross-section places real gold atoms on a (100) plane (atoms drawn only up to 10 nm). Real nanoparticles also have edges, corners and facet-dependent coordination, which this simple model ignores.
